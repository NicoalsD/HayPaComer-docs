# Sprint 3: plan de pruebas

[`Plan de Pruebas HayPaComer.xlsx`](Plan%20de%20Pruebas%20HayPaComer.xlsx) es el plan de pruebas en la plantilla del curso. Tiene dos hojas:

- **Plan de Pruebas:** cada caso con su ID, tipo, responsable, descripción, clase y método que prueba, datos de entrada, resultado esperado, resultado obtenido y si pasó. Los casos `QA` son pruebas unitarias y los `QC`, de integración.
- **Resumen:** totales por tipo y entorno de ejecución.

Cómo se automatizó cada caso, con la captura de su código y de su resultado, está en el [sprint 4](../sprint-4/casos-del-plan-automatizados.md).
